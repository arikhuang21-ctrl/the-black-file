# The Black File

An interactive mystery archive created for the CCT360 Interactive Discovery assignment.

## Project overview

Three connected case files lead the player through an abandoned detective office, a recurring address, and a final choice. The experience uses vanilla HTML, CSS, and JavaScript with state-based progression, clue collection, browser storage, responsive layout, image evidence, and three possible endings.

## Run locally

Open `index.html` in a browser, or serve the folder with a local static web server.
